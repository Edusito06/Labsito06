# Lab 6 – IoT (Android, Java, API 34)

Proyecto Gradle completo. Abrir con **Android Studio → File → Open → carpeta `Lab6App`**
(la que contiene `settings.gradle`) y esperar el Gradle Sync.

Antes de que funcione el login y la base de datos hay que configurar Firebase y Facebook.
Sigue **[GUIA_CONFIGURACION.md](GUIA_CONFIGURACION.md)** paso a paso.

Archivos que debes reemplazar con los tuyos:
- `app/google-services.json` (ahora es un placeholder)
- `app/src/main/res/values/strings.xml` (App ID y Client Token de Facebook)
